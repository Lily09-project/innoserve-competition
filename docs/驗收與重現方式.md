# 驗收與重現方式

## 環境分層

- `requirements-test.txt`：公開合約測試；不載入真實權重，不操作正式網路。
- `requirements.txt`：模型推論環境；本次RTX 4090、PyTorch 2.7.1＋CUDA 12.6通過。Python、CUDA與權重仍須依本機配置。
- `requirements-media.txt`：實際圖文製作環境；另需Microsoft PowerPoint、標楷體與Times New Roman。PDF供跨設備閱讀，字型不隨公開庫散布。
- `pnpm-lock.yaml`：固定jsdom、sharp等媒體檢查依賴。Node製作工具優先使用專案依賴，亦保留既有RENDER_NODE_MODULES覆寫方式。
- 完整影片渲染另外設定`FFMPEG_BINARY`至現有合法編碼器。單純CI九章影像編譯不需要FFmpeg、PowerPoint或私有模型。

## 公開版驗收

```bash
git submodule update --init --recursive
python -m pip install -r requirements-test.txt
python -m unittest discover -s tests -v
pnpm install --frozen-lockfile
pnpm run test:media
node tests/media-render-smoke.cjs
python scripts/check_delivery_docs.py
python scripts/check_public_files.py
```

合約測試中的合成fixture只驗證程式。模型成效仍來自封存18,998筆測試、463筆檢索稽核及本機真實整合證據，不能把CI通過當成重跑模型。

## 私有工作站驗收

1. 資產路徑與WSL配置放在Git忽略的`config.local.json`；環境變數`INNOSERVE_欄名大寫`優先。相對資產路徑以專案根目錄為準，不隨執行目錄改變。
2. 以`python scripts/preflight.py`做預檢，只有加`--warmup`才可能預載模型；任一前置檢查失敗就不預載。預檢不部署網路政策，報告另存時間戳檔案，不覆寫舊證據。
3. 模型或流程有實質變更時執行`python scripts/audit_final_chain.py`；它會重跑17類、17次本機AI及預定6種隔離情境。
4. 用`python scripts/audit_alignment_assets.py --audit-dir PATH_TO_SUCCESSFUL_AUDIT`核對來源、權重、正式類別與案例排序。
5. 用`python scripts/export_framework_validation.py --audit-dir PATH_TO_SUCCESSFUL_AUDIT`匯出公開彙整。未指定目錄時只選最新成功、完整且來源指紋相符的紀錄；明確指定錯誤目錄時直接失敗，不偷偷改選。
6. 正式視覺檔驗收後執行`python scripts/release_inventory.py --audit-dir PATH_TO_SUCCESSFUL_AUDIT`，產生公開證據索引與來源綁定，再更新交付manifest。

## 匯入與工作保留

匯入只接受分離、非巢狀來源，拒絕連結與特殊檔。先複製至自己擁有的暫存目錄、完成檢查後才發布到`evidence/fresh17`。已有目標（包含空目錄）也不覆寫；失敗只清理本次暫存，不移除其他資料。匯入是完整搬入，不合併既有資料。

API預設保留最多128筆已完成工作，保留時間3600秒；進入新工作或查詢工作時清理。執行中工作不清除，實際事件與網路回條保存在獨立證據目錄，不隨工作清理消失。

## 範圍與停止條件

本次不重新訓練、修改判定門檻或替換案例庫，也沒有重畫已驗收的視覺成果。模型與方法不變時不為版面變更反覆執行GPU或隔離實驗。

原生播放依使用者指示不做。使用已解碼影片、連續時間戳、內嵌與外部檔一致性、影格與字型幾何檢查；這些結果不被描述為實播通過。

發布前完成[測試矩陣](測試矩陣.md)、文件與雜湊稽核、CI及遠端主分支一致性。公開庫不含私有部署資產；缺資產時明確報錯，不補虛假資料。

本次另在不含`config.local.json`與`evidence/`的乾淨clone執行104項測試及九章影像編譯，全部通過。首次clone必須初始化第三方子模組；缺少時會出現來源元件import錯誤，不能因此以fixture補上真實元件。
