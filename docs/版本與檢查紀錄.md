## 檢查方式

```bash
python scripts/check_delivery_docs.py
python -m unittest discover -s tests -v
pnpm run test:media
pnpm run check:media
python scripts/check_public_files.py
```

Markdown檢查器盤點Git追蹤與本次新增的自有.md，核對本機連結、交付雜湊及MP4實際時長。製作中的PPT Master工作目錄另同步design_spec、spec_lock與notes；不把第三方文件改成自有作品說明。

資料來源仍是results四份實測彙整，沒有新增或修改實驗數值。正式PPT、PDF、影片及架構圖的SHA-256列於[交付紀錄](../deliverables/source/delivery-manifest.json)。逐頁視覺檢查與獨立終檢紀錄保存在本機validation，雲端則由CI檢查文件連結、資料合約與交付完整性。

本次覆核15份自有Markdown、23個本機連結，29項合約與資料檢查通過。正式影片實測30.0秒、2倍速，720幀完整解碼成功；PowerPoint實際輸出12頁經逐頁檢查，影片經關鍵幀與成片抽幀獨立複查。正式演練配置為五分鐘，包含影片與正常操作，另留一分鐘緩衝；實際口語時長由完整彩排確認。

本機API已切換至本次交付目錄的程式，重新執行17類本機模型與17次本機AI稽核，並完成6種隔離TCP情境。六種情境均保留背景服務及完成回復，過期執行ID遭拒，回條綁定同次事件與執行。3個模型權重雜湊與案例庫來源一致；463筆稽核輸入不含真實標籤。新推論與保存結果的17類判定及Top-5案例排序均一致，類別機率最大絕對差為0.000119884，屬實際量測差異，不宣稱逐位元相同。

展前檢查改以設定中的模型Python檢查CUDA，與推論工作程序使用相同環境；私有資產、模型來源、CUDA、WSL隔離與模型服務皆通過。私有權重、輸入、逐筆AI回覆與網路回條保留在Git忽略目錄，不上傳公開庫。公開程式與實驗彙整不包含模型權重，因此下載公開庫後仍需配置本機資產。

投影片實際由PowerPoint開啟並輸出12頁，交付封裝保留原始XML命名空間，作者欄位為空。新增中繼資料命名空間及淺色背景檢查，避免可解析XML卻無法正常開檔的問題。影片保持30秒、2倍速，簡報與影片均改為白底、淺灰面板及藍色重點。

本輪驗證範圍為前處理張量、本機模型與隔離TCP交易；即時擷取任意PCAP、原生攻擊重放及正式場域防禦率未列為已驗證功能。完整新訓練與18,998筆全量重新評估未在本輪重跑；既有四份results的數值與混淆矩陣持續通過一致性檢查。

## 開場影片順序與字型

內嵌影片頁移至第2頁，封面後先呈現，再從第3頁說明架構。中文及中文標點為標楷體DFKai-SB，英文、數字及其他符號為Times New Roman；混合文字在同一文字框依字元設定。原生PPT另明確指定East Asian與Latin字型，講者備忘稿同樣套用。頁碼、來源SVG、架構PNG、講稿與五分鐘配置同步，影片已內嵌，無換頁特效及物件動畫。

## 內嵌開場影片與精修

第二頁由影片位置升級為原生內嵌H.264影片，30秒、2倍速，與獨立MP4逐位元一致。PowerPoint實際播放讀值由約5秒持續至25秒，30秒後停止，35秒時仍在第二頁，未循環或跳頁。媒體播放時序是影片正常播放所需，其他頁面沒有物件動畫或換頁特效。

影片新增電腦、交換器、防火牆與伺服器專屬圖示、六階段導覽、拓樸底板及證據面板；最後1.5秒為獨立結束畫面。PPT統一標題標記、頁尾對齊與留白，末頁補上答詢提示。中文標楷體與Times New Roman同步套用簡報、備忘稿及影片，實驗數值維持原值。
