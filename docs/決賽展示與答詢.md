# 決賽展示與答詢

現場簡報含展示共6分鐘，答詢7分鐘。採匿名審查，交付物不包含學校名稱、校徽、指導老師或其他可識別資訊。

## 展示順序

1. 開啟8頁正式簡報，先用四分塊架構圖說明同一事件如何從流量表徵進入17類判定，再到案例檢索、AI稽核與受控處置。
2. 說明三項創新：互補模型融合、529維任務檢索、本機證據稽核及可驗證回復。
3. 播放獨立的30秒方法動畫。動畫以拓樸、封包及模型支線說明流程，量測成果另列範圍。
4. 以相同18,998筆的模型比較與463筆檢索稽核結果呈現實際效果。六種隔離驗證呈現背景服務與回復完整性。
5. 答詢時提供results四份彙整，以及私有交付包中的同事件回條；私有模型與逐筆資料留在本機。

## 數據口徑

- Accuracy 98.08%、Macro-F1 93.05%：18,998筆封存測試。
- PBCNN、CTBM、OOF Gate Macro-F1分別79.75%、92.10%、93.05%，使用相同測試集。
- Top-5 97.62%、MRR@5 93.89%：1,550筆訓練案例、463筆查詢，訓練與查詢不重疊。
- 本機AI同463筆：415支持、13複核、35不確定；支持精確率97.11%。30筆誤判有18筆分流，12筆獲支持。
- 真實張量鏈路驗證涵蓋17類；不是任意PCAP上傳入口。
- 六種隔離情境為4種套用規則、2種監測或蒐證；背景6/6、回復6/6。效果是隔離TCP測試交易及回條，非正式場域攻擊防禦率。

## 現場備援

準備本機PPTX、MP4、架構PNG、results與私有回條。影片獨立播放，簡報保留備忘稿。GitHub只作檔案交付與原始碼入口，不提供公開網站。本機API與模型仍可執行；先完成資產設定，再啟動服務並執行scripts/preflight.py --warmup。離線回放回條時明確說明為先前量測紀錄。
