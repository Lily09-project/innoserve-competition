# 決賽展示與答詢

現場簡報上限6分鐘，正式內容規劃5分鐘，另保留1分鐘緩衝；答詢7分鐘。採匿名審查，交付物不包含學校名稱、校徽、指導老師或其他可識別資訊。

## 展示順序

1. 第1頁介紹作品定位，接第2頁全幅內嵌動畫，先展現完整事件流程。
2. 第3至6頁依序說明總架構、互補模型、任務檢索與AI稽核、受控處置及回復。
3. 第7、8頁分別說明同18,998筆的模型比較，以及463筆檢索稽核結果。
4. 第9頁結束正式報告；第10至12頁為6題答詢備用，依評審問題切換，不在正式報告主動講述。
5. 答詢時可搭配results四份彙整及本機私有回條；不投影帳號、個人路徑或私有紀錄。影片同一MP4另作備援。

## 數據口徑

- Accuracy 98.08%、Macro-F1 93.05%：18,998筆封存測試。
- PBCNN、CTBM、OOF Gate Macro-F1分別79.75%、92.10%、93.05%，使用相同測試集。
- Top-5 97.62%、MRR@5 93.89%：1,550筆訓練案例、463筆查詢，訓練與查詢不重疊。
- 本機AI同463筆：415支持、13複核、35不確定；支持精確率97.11%。30筆誤判有18筆分流，12筆獲支持。
- 真實張量鏈路驗證涵蓋17類；不是任意PCAP上傳入口。
- 六種隔離情境為4種套用規則、2種監測或蒐證；背景6/6、回復6/6。效果是隔離TCP測試交易及回條，非正式場域攻擊防禦率。

## 現場備援

準備本機PPTX、MP4、架構PNG、results與私有回條。影片在第二頁內嵌播放，簡報保留備忘稿。GitHub只作檔案交付與原始碼入口，不提供公開網站。本機API與模型仍可執行；先完成資產設定，再啟動服務並執行scripts/preflight.py --warmup。離線回放回條時明確說明為先前量測紀錄。

## 海報與本機操作

A2海報以四階段架構、三項創新與分階段實測為主，採420×594mm直式，沿用簡報的淺色視覺與字型，提供可編輯PPTX及印刷PDF。內容依[決賽內容基準](決賽內容基準.md)統一，詳見[海報輸出規格](../deliverables/source/poster-a2-spec.md)。

答詢需要實際執行時，依[本機展示操作單](本機展示操作單.md)使用匿名終端工具；畫面會區分即時模型及保存結果模式。工具驗證同事件紀錄與同次隔離回條，不顯示個人路徑、來源IP或模型原始回覆。正式六分鐘流程仍以簡報為主，隔離測試及30秒回復不另外塞入原有五分鐘配置。
