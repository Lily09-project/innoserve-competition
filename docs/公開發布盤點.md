盤點開始時本機HEAD與GitHub的main一致，沒有未推送提交、工作區修改或未追蹤的公開檔案。不過，正式PPT已更新，`deliverables/source/slides/`的12張公開SVG仍停留在先前版面。本輪已逐張同步至最新製作來源，並將12張SVG加入交付manifest的LF正規化雜湊檢查。

## 保留本機內容

`evidence/`、模型權重、原始流量、案例向量、逐筆Judge回覆、私有回條、`config.local.json`、環境憑證、`runtime/`、`validation/`、`projects/`及依賴快取均依既有公開政策保留本機。它們不是待推送的正式公開檔案。

對被忽略檔案另以路徑分類盤點；app、scripts、media、docs、design-system及deliverables等公開目錄內，沒有被忽略而遺漏的正式來源。製作工作目錄中的正式設計規格、講者稿與逐頁SVG另有對應公開副本；暫存匯出、舊版與診斷圖不整批上傳。

## 驗收與推送

1. 比對本機與遠端main，確認新增與未追蹤清單。
2. 核對12張公開SVG與目前正式製作來源，更新交付清單。
3. 執行104項Python測試、文件連結與交付雜湊、公開檔案稽核及媒體編譯檢查。
4. 以PR提交，等GitHub CI通過後合併；不調降分支保護。
5. 取得合併後main，確認工作區乾淨、本機與遠端SHA及內容一致。

本輪未改模型程式、權重、實測數值或正式PPT／影片／海報版面；修正的是公開來源同步及文件完整度。最新版本以[README](../README.md)、[交付清單](../deliverables/source/delivery-manifest.json)與GitHub主分支為準。
