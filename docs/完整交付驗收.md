- 三項成果維持白與淺灰底，使用深藍、中藍、金黃及墨色，中文標楷體、英文數字Times New Roman。

- 依使用者指示，本輪不做播放測試。改以檔案與程式驗收：完整解碼720幀、PTS由0至719連續、24fps／1920×1080、內外MP4逐位元組一致；另檢查32張轉場前後影格。這些檢查不被描述為PowerPoint原生實播通過。

## 匿名與交付

匿名掃描涵蓋簡報、海報的文字、備忘稿、關聯與中繼資料，另檢查架構圖及影片來源。公開庫帳號、作者等已知識別字串不進入匿名交付物；模型、案例庫、逐筆回覆及回條留在本機。

離線包內的簡報、影片、海報及講者稿均與交付版相同，附SHA256清單。文件連結、交付雜湊、媒體時長、字型及資料一致性納入回歸檢查。完整部署仍使用已配置私有資產的工作站。
