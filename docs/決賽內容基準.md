# 決賽內容基準

此表供簡報、影片、A2海報與答詢共同使用。數據以results四份JSON為準；單筆展示不改寫封存實驗結果。

## 作品與方法

- 正式名稱：融合新型內容相依時序方向模型入侵偵測與任務導向檢索增強稽核之 AI 資安框架。
- 定位：同一事件串接流量判定、訓練案例證據、本機AI稽核與受控處置回條。
- CTBM讀取內容、時間差與方向；PBCNN補充短窗位元組模式，經校準與OOF Gate形成17類正式判定。
- 512維表徵與17維類別機率組成529維任務向量，L2正規化後檢索訓練案例Top-5。
- 本機AI輸出支持、複核或不確定，保留正式分類。策略另檢查信心、證據、範圍、動作白名單及期限。
- 處置展示涵蓋隔離環境的規則套用、讀回、到期撤銷與交易回復；每次執行使用獨立識別碼。

## 一致性與匿名

中文微軟正黑體，英文與數字Segoe UI；淺灰底封面、結尾與影片，白底內頁、訊號藍流程、青綠成果與少量琥珀標示目前步驟。正式簡報12頁，9頁正式內容及3頁六題答詢。影片30秒、2倍速、位於封面後。

投影材料不包含學校名稱、校徽、教師姓名、個人帳號或私有路徑。公開GitHub僅作交付與查核入口，不放入匿名海報或投影畫面。
