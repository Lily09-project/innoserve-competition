# 展前驗收與備援

## 電腦已驗證的部分

- 正式簡報維持12頁，第2頁內嵌30秒影片；字型、頁序、六題備詢及影片位元組由交付測試保護。
- A2海報已以Microsoft PowerPoint實際開啟，輸出單頁PDF與PNG，檢查文字、箭頭及數值排版。
- 海報PDF使用PDF/A輸出，中英文字型皆嵌入。PPTX尺寸420×594mm，PDF換算約419.99×593.98mm，屬PowerPoint匯出取整差異。
- 本機預檢五項通過：私有資產、三份模型版本、CUDA、隔離工具及API。
- 匿名工具完成一筆SSH事件的本機推論、Top-5、AI支持、策略、兩條隔離規則及30秒到期回復；回條綁定、背景與回復交易通過。
- 保存結果模式重新檢索並明示來源，沒有套用網路規則。
- 上述單筆工具檢查沒有新增整體準確率、延遲或原生攻擊防禦率宣稱。

## 講者與現場人員執行

| 動作 | 通過條件 | 處理方式 |
| --- | --- | --- |
| 兩次完整朗讀 | 每次含影片與換頁均在五分鐘內 | 超時先刪重複口語，不縮小字體或加速到難以理解 |
| 接投影機播放 | 字體清楚、16:9正常、第2頁影片播放一次 | 備獨立MP4及PDF |
| 六題答詢演練 | 先一句話回答，再指圖與證據 | 不臨時宣稱超出實測範圍的功能 |
| 海報局部實尺寸打樣 | 方法與圖表標籤可讀，無裁切 | 先調排版，再依印刷廠確認紙材及出血 |
| 匿名檢查 | 無校名、校徽、姓名、帳號、個人路徑與通知 | 投影前清畫面，公開GitHub不投影 |
| 離線備援 | 隨身碟可開PPTX、PDF與MP4 | 使用決賽離線展示包，核對雜湊 |

人工朗讀、場地投影與實體印刷應在實際條件確認。本機程式檢查不能代替這三項。

## 備援切換

1. 影片異常：改開獨立MP4，結束後回第3頁。
2. PPT異常：使用PDF，第2頁影片另以MP4播放。
3. 模型或API異常：答詢改用保存的真實紀錄，清楚說明來源；不在正式報告中重載模型或反覆排錯。
4. 隔離測試已啟動：等待回復完成再關閉工具，不中斷30秒期限。

## 固定交付版

離線展示包含簡報、影片、海報、講者備忘稿、五分鐘口語稿、六題答詢、控場備援卡及流程設定，沒有私有權重、案例庫與逐筆事件，也不等同完整部署包。改動上述任一資產後，重新執行scripts/package_finals.py並更新delivery-manifest.json雜湊，最後執行文件及交付測試。


## 離線互動示意

離線包另包含互動HTML；下載後用瀏覽器開啟，預設2倍速約36.5秒，可暫停與跳轉。本頁展示合成封包、示意分類與回覆，不能當成即時模型展演或實測結果。需要真實模型時仍使用已配置工作站的匿名控制台。
