# 互動展示 UX 檢查

依 UI/UX Pro Max 的 keyboard-nav、focus-states、auto-rotation-controls、reduced-motion、skip-links 與 keyboard-shortcuts 檢查現有HTML。保留既定色盤、DFKai-SB／Times New Roman及單檔離線模式，不重建新設計系統。

| 檢查 | 發現與修正 | 驗證 |
| --- | --- | --- |
| 鍵盤閱讀 | 焦點進入圖面或觀察窗時，原先會繼續輪播；現在先暫停且不重建焦點元素 | 焦點、播放狀態、時間維持 |
| 動態偏好 | 原先只讀取初始設定；現在監聽設定變更，啟用減少動態立即暫停，停用不重播 | 兩次設定切換 |
| 說明對話框 | 新增標題關聯、關閉按鈕初始焦點及離開後焦點回復 | 名稱非空、初始及返回控制 |
| 全域快捷鍵 | 原先可能攔截修飾鍵方向鍵；現在保留Ctrl／Alt／Command及輸入法組字 | Ctrl＋方向鍵未攔截、時間不跳轉 |
| 快速入口 | 新增跳至方法圖與播放控制的鍵盤入口 | 目標存在、可聚焦 |
| 範圍與可讀性 | 原配色、中文標點字型、縮放、專注模式與響應式規則保留；對話框最大高度限制於視窗並可捲動 | 固定色碼與字型回歸、DOM結構與操作 |

完整四情境、48狀態、8次循環、倍率、專注、章節、鍵盤、匯出與離線重新開啟測試重跑。技能聚焦互動介面，本輪未改PPT、海報或影片。

真實瀏覽器、讀屏軟體、現場投影及原生播放未執行，不宣稱全面WCAG符合。DOM測試的SVG幾何使用替身，無法代替版面檢視。
