# 決賽穩定性、風險分析與操作整合

此版整合異常復原、策略風險盤點、情境展示與交付封裝；正式簡報、影片與海報維持已核對的淺色版面及兩種字型。

## 隔離工作的成功條件

Mininet工作在Linux端設定期限，SIGALRM、SIGTERM及SIGINT會轉入清理流程。專案鎖拒絕同時啟動另一套測試網路；不使用全域mn清除命令。網路物件一建立即記錄所有權，部分啟動失敗也能清理。

成功回條除原有交易、規則讀回及到期回復外，還需確認規則清除、測試服務結束、網路停止、無殘留專案介面。沒有清理證明就拒絕成功。回條、進度或清理紀錄已存在時不覆寫；每次操作建立新工作目錄。

模型載入或推論失敗會留下明確工作狀態及錯誤碼；診斷檔無法寫入時也不讓工作永久停在執行中。執行中工作拒絕停止服務，服務停止後不再接受新工作。失敗訊息不揭露模型原始回覆或私有路徑。

[復原驗證彙整](../deliverables/source/recovery-validation.json)記錄隔離場景的期限中止、訊號中斷、併發拒絕及清理後重試，四項皆通過。中斷正在讀取輸出的交易時，清理流程先中止並收完專案節點的命令輸出，再清除規則及停止網路。這項驗證不增加模型呼叫數，不列為真實攻擊防禦率；也不宣稱能在作業系統強制斷電或SIGKILL後執行Python finally。

## 策略風險與弱項分析

[策略風險分析](../results/policy_risk_analysis.json)對463筆保存事件重新檢索及執行策略檢查，未部署網路規則。30筆偵測誤判中12筆獲AI支持；其中6筆被策略擋下，另外6筆仍獲允許介入。後者是策略授權數，不是實際誤封數，也沒有藉此宣稱誤封率為零。

錯誤支持集中於Web-BruteForce、Web-XSS與SQL-Injection之間的混淆。彙整提供實際驗證標籤、預測類別、策略與數量，不包含事件身分或原始資料。Web-XSS及Web-BruteForce另列出18,998筆封存測試的F1、支援數、主要混淆，以及463筆查詢內的稽核和策略分布；這兩個評估範圍分開呈現。

本輪保留封存模型與切分，不依測試答案提高門檻或重訓來美化結果。若進一步改善模型，應另以訓練及驗證資料處理類別不平衡與特徵，再使用保留測試集確認，不能把展示17筆當作整體準確率。

## 一鍵匿名展示

Windows直接開啟根目錄的[決賽展示.cmd](../決賽展示.cmd)。控制台以正常、FTP、SSH、HTTP、Bot及複核情境定位事件；依保存判定選擇，本次結果以模型實際輸出為準。保存結果備援不預載模型、不執行網路規則，也不會被描述為即時推論。

```bash
python scripts/showcase.py --prepare-only
python scripts/showcase.py --scenario ssh --mode live --network
python scripts/showcase.py --scenario review --mode saved
```

準備入口核對API與目前來源版本，拒絕接管其他服務或舊版本；啟動逾時只結束自己啟動的程序。離開控制台保留本機服務，執行中的隔離工作依期限及清理流程結束。日誌與逐筆資料保留本機。

## 交付驗證及封裝入口

```bash
python scripts/finals_pipeline.py
python scripts/finals_pipeline.py --stage validation/NEW_DELIVERY_FOLDER
```

入口執行媒體快照、完整Python測試、九章節SVG與影像編譯、數據更新、文件雜湊及公開檔案檢查，任一步失敗即停止。封裝重新產生12頁SVG，核對正式來源後，將核准的原生PPT、PDF、影片、海報、講者稿、離線包與雜湊清單複製到新的validation子目錄。

此入口重現目前核准的交付，不自動重新設計原生投影片。SVG若改變，會停止並要求先完成原生匯出及版面驗證，避免將新SVG與舊PPT混合發布。正式影片不重新轉碼，保留已核對的內外嵌位元組。

需要更新模型驗收證據時，先重新預檢、執行audit_final_chain，再使用：

```bash
python scripts/finals_pipeline.py --refresh-evidence --audit-dir PATH_TO_SUCCESSFUL_AUDIT
```

工具依序核對資產、匯出整合結果、重算策略風險、更新媒體快照及發布索引。更新失敗會還原原有公開結果與索引，保留本機備份及診斷。證據刷新不是模型實驗的替代步驟。

## 決賽封存

正式封存須使用通過CI的主分支提交，以固定Git標籤與GitHub Release提供正式簡報、影片、海報、離線包及SHA256清單。現場設備與備援隨身碟使用同一批檔案。原生播放依使用者要求不列本輪驗收；講者彩排、場地投影與實體印刷另按展前操作單確認。

乾淨clone驗證不含config.local.json或evidence，127項測試、九章節編譯、資料更新測試及一鍵封裝通過。163個公開Git路徑稽核為0 findings；正式PPT、PDF、MP4、海報與離線ZIP均維持原檔。
