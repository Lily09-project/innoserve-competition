# 架構圖設計與驗收

## 參考要求的採用方式

已讀取使用者既有的IDS v41同步PPT成果、橫式流程圖v22要求，以及另一篇論文的RAG緊密統一主色版與完整架構圖規劃。這些檔案只作唯讀參考，原稿未修改，也未複製其他研究的數值到本作品。

採用共同原則：大區塊下再分子模組；資料流與讀取關係分清楚；平行模型先分支再融合；箭頭接到框邊；線路不穿字；圖示等比例；文字、邊框與箭頭保持可編輯。其他論文的字型、論文印刷字級及專屬資料流程不直接套用本次決賽。

## 本版架構

- 上層：a流量表徵；b雙模型並行、校準融合與17類判定。
- 下層：c任務向量、Top-5訓練案例及本機AI稽核；d策略檢查、套用、讀回與到期回復。
- CTBM與PBCNN讀取同一事件的不同特徵，兩者並行，沒有CTBM輸出再進PBCNN的串行關係。
- 前段交接內容為正式類別、信心與模型表徵；512維表徵與17維機率組成529維任務向量。
- 實線表示事件流程；虛線表示訓練案例讀取。底部橫帶表示各產物共用事件ID，並非回寫案例庫或線上持續訓練。
- 本機AI不改寫正式分類；複核與不確定事件進入蒐證路徑。可干預策略仍受閘門門檻控制。

## 比例與可編輯性

架構SVG為1280×536，PNG為2560×1072。PPT第2頁以原比例放入，不做水平或垂直拉伸；核心標籤20–24px，投影輸出後逐區檢查。圖示重用同一組AI生成的無文字素材，字與連線由Python繪製；不把整個架構圖壓成PPT背景圖片。

第3頁偵測方法採原生可編輯的分流／匯流圖，與第2頁的雙模型平行關係一致。正文使用微軟正黑體／Arial與淺色底與藍色重點設計，維持整份簡報及影片的共同視覺。

## 驗收依據

檢查SVG端點、圖示比例與文字邊界，再以Microsoft PowerPoint實際匯出9頁及PDF逐頁回看。正式影片另外抽取各章關鍵幀、轉場附近畫面及檔頭，確認30秒、2倍速、1080p、24fps。這是抽樣視覺檢查，不宣稱每個影格均逐格驗收。
