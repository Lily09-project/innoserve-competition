# 本機展示操作單

本單供操作者使用。正式報告以離線簡報為主，本機流程供展前確認與答詢展示；17類批次重跑不塞進六分鐘報告。

## 展前準備

1. 將正式PPTX、PDF、30秒MP4及A2海報PDF放入備援隨身碟。PPTX內已包含同一影片。
2. 使用已設定私有模型、案例庫、CUDA及WSL的展示工作站；公開GitHub不含這些私有資產。
3. 執行「啟動作品.cmd」，在非投影畫面啟動API。若已有服務執行，直接檢查，不重複啟動。
4. 在專案根目錄執行以下指令，五項皆PASS且最後為READY才進行模型展示。

```powershell
python scripts/preflight.py --warmup
```

預檢涵蓋私有資產、三份權重與案例版本、CUDA、WSL隔離工具及API。預檢本身不套用網路規則。

API狀態另外提供主要程式模組的來源指紋，預檢會比對目前專案，避免程式已更新但仍展示舊服務。指紋不包含個人路徑；這是版本一致性檢查，不是數位簽章。

## 匿名終端展示

先在非投影畫面切到專案目錄。使用全螢幕終端，關閉通知與終端標題列；PowerShell可於此視窗暫時設定簡單提示字元並清畫面，避免顯示個人路徑。

```powershell
function prompt { '展示> ' }
Clear-Host
python scripts/demo_walkthrough.py --mode live --event-index 1
```

工具僅輸出匿名事件代碼、正式判定、信心、Top-5類別與相似度、稽核結論及策略。模型原始回覆、真實標籤、來源IP、權重路徑與案例識別碼不投影。匿名代碼仍可在同次展示中核對前後產物。

輸出前會逐欄核對四階段順序、正式判定、17類機率與信心、Top-5排序及證據雜湊、稽核與策略紀錄，並區分即時／保存模式。欄位不一致即中止展示，不印出「驗證通過」。

`--event-index`是API輸入清單的位置，範圍0至16，不等於類別編號。操作者應先試跑並依實際輸出選擇情境，不能把索引當作預先保證的判定。

## 展示規則讀回與到期回復

以下指令重新執行本機模型，再將同次結果送往隔離Mininet測試；規則限於隔離命名空間，期限為30秒。需等待完整回復，不能中途關閉程式。

```powershell
python scripts/demo_walkthrough.py --mode live --event-index 1 --network
```

本次工具驗證使用SSH-Bruteforce事件：支持、auth_hardening、2條規則、背景交易成功率1.0、回復後交易成功率1.0，回復完整性及同次回條驗證通過。這是單筆展示工具的確認，不取代results中的6種情境統計。

不是全部17類都有隔離交易設定；可用隔離類別見framework_validation.json。輸入類別不適用時，先保留模型與稽核結果，改用有對應隔離設定的事件。正式判定或稽核結果變化時，以實際結果為準，不為展示改寫輸出。

## 保存結果備援

模型展示無法執行時，先向評審說明使用保存的模型判定及稽核回覆，檢索仍重新計算，再執行：

```powershell
python scripts/demo_walkthrough.py --mode saved --event-index 1
```

此模式禁止搭配`--network`。畫面會明示執行模式，不能當成剛完成的模型推論。若API也無法使用，改以離線PDF、MP4、results與保存的真實回條解說，停止重試，以保留報告時間。

## 成功與中止判斷

- 成功：出現「同事件四階段紀錄：驗證通過」；隔離展示另出現同次回條通過及回復完整性True。
- 無`--network`時沒有套用規則，畫面會明示。
- 摘要保存在Git忽略的validation/demo-walkthrough-summary.json，不自動上傳。
- 出現「展示中止」時切回非投影畫面檢查診斷，不將原始traceback投影。
- 不刪除既有回條、不重訓模型，也不把逐筆耗時當作整體效能統計。

## 實際彩排紀錄

由講者在正式設備進行兩次完整朗讀，記錄影片、換頁及口語總時間，目標五分鐘內完成。檢查接上投影機後的字級、長寬比及影片播放。這項人工彩排及海報實體打樣須由現場人員完成，電腦輸出檢查不能代替。

## 一鍵情境控制台

直接執行決賽展示.cmd；或使用python scripts/showcase.py --prepare-only。預檢通過後可由名稱選擇正常、FTP、SSH、HTTP、Bot及複核／不確定情境。情境依保存判定定位，本次結果仍由模型決定。可用--scenario ssh --mode live --network執行完整隔離流程；--scenario review --mode saved只使用保存結果備援，不預載模型或套用規則。

隔離工作有Linux端期限、專案鎖與清理回條。離開控制台不強制停止模型API；若隔離工作正在執行，等待期限及清理完成再關閉設備。
