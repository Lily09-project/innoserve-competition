# 現場控場與備援卡

操作者使用。先在非投影畫面準備，正式畫面只保留簡報、匿名終端或獨立影片。

## 報告主線

封面 → 第2頁30秒影片 → 第3至6頁方法 → 第7、8頁結果 → 第9頁結語。第10至12頁僅在答詢使用。五分鐘是報告目標，剩餘一分鐘處理停頓及操作，不另加內容。

| 狀況 | 立即動作 | 回到哪裡 |
| --- | --- | --- |
| 內嵌影片異常 | 播放同一份獨立30秒MP4；若播放器仍失敗，指第3頁完整流程解說 | 第3頁 |
| PowerPoint異常 | 改開正式PDF；影片另開MP4 | 原頁次 |
| 正式報告時間不足 | 第7、8頁各口述一個核心數據，略過重複說明 | 第9頁結語 |
| 模型未完成預載或錯誤 | 說明改用保存結果，使用saved模式 | 同事件摘要 |
| API也無法使用 | 使用PPT／PDF圖解與已保存的正式結果，停止反覆重試 | 對應備詢頁 |
| 隔離工作正在執行 | 等待期限回復與清理完成；不要強制關閉設備 | 同次回條 |

備援不是即時推論。切換時說：「這裡改用先前保存的模型判定與稽核紀錄，案例檢索會重新計算。」若API未啟動，改為離線文件解說，不聲稱重新檢索。

## 展前預載

```powershell
python scripts/showcase.py --prepare-only
```

五項PASS且顯示READY後，再準備投影畫面。關閉通知、隱藏帳號與個人路徑，使用全螢幕終端及簡單提示字元。

## 同事件完整展演

```powershell
python scripts/showcase.py --scenario ssh --mode live --network
```

讀取順序：同一事件代碼 → 正式判定與信心 → Top-5 → AI稽核 → 策略 → 規則數 → 背景交易 → 回復完整性。這是隔離TCP交易驗證；實際輸出以本次模型為準，不預先保證支持或套用規則。完整展演安排在評審要求展演或答詢時，不另塞入既有五分鐘主線。

其他即時判讀：`--scenario normal`、`ftp`、`http`或`bot`，加上`--mode live`；沒有`--network`就不套用網路規則。選情境使用名稱，不把事件索引當成類別編號。

## 保存結果備援

```powershell
python scripts/showcase.py --scenario review --mode saved
```

保存模式不載入模型、不套用網路規則。若要求查看原始證據，在非投影畫面查找，再用匿名摘要說明，不直接投影私有逐筆紀錄。

## 上台前最後確認

正式PPTX、PDF、30秒MP4、海報PDF及本卡都在備援媒體中，並與離線包SHA256清單一致。核對淺灰底封面與白底內頁、中文微軟正黑體及英文／數字Segoe UI；PPT第2頁有影片、第9頁有結語、第10至12頁是備詢。實際朗讀、場地投影可讀性及海報打樣由現場人員確認。依使用者指示，本輪不操作影片實播驗證。
