## 後續更新方式

1. 模型執行程式或資產變更後，先重新預檢並取得成功整合驗收，再執行資產對齊與公開彙整匯出。
2. 執行python scripts/media_results.py及--check，驗證四份彙整並更新快照。快照不能替代模型實測。
3. 指標改變時重製媒體、原生圖文、預覽及離線包；同步字型、對齊與匿名驗證。
4. 產生新的release-validation及delivery-manifest，執行完整測試、文件連結與公開檔案稽核，通過CI後發布。
