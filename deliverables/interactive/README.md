# 自動循環展示

[線上開啟互動展示](https://lily09-project.github.io/innoserve-competition/deliverables/interactive/AI%E8%B3%87%E5%AE%89%E6%A1%86%E6%9E%B6_%E8%87%AA%E5%8B%95%E5%BE%AA%E7%92%B0%E5%B1%95%E7%A4%BA.html)（GitHub Pages 直接發布此單檔），或[下載 HTML 單檔](AI資安框架_自動循環展示.html)以瀏覽器離線開啟。無需登入、套件或模型服務；離線開啟也不需連網。

## 決賽展示

開啟後先播放 HTTP 洪流，再循環正常連線、SSH 驗證嘗試與可疑 Web 流量。四張卡片依序呈現辨識流量、找相似案例、核對證據、決定處置。情境最後分別示意限速、持續監測、限制登入連線或人工複核。每個情境 38 秒，可切換 1、1.5、2 倍速。

可選情境、暫停、重播、拖曳時間軸或點選四站導覽。按 P 或使用「投影模式」切換投影，按 Esc 離開。Space 切換播放，方向鍵前後 5 秒。啟用系統的「減少動態效果」時由觀眾手動開始。答詢可展開頁底三個重點，播放會暫停。

## 資料範圍與驗證

所有情境使用合成封包與示意模型回覆。頁面呈現到處置決定送達，隔離連線回復另見簡報第 6 頁及影片片尾的 Mininet 實測。展示秒數是操作節奏。

四情境及播放控制使用離線 DOM 測試。手機及投影模式用 Edge 檢查。需要核對原本的編碼、向量與策略細節時，可用 `?technical` 開啟技術檢視。
