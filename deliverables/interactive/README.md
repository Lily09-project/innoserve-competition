# 離線互動展示

[下載／開啟HTML單檔](AI資安框架_離線互動展示.html)，以一般瀏覽器開啟即可，不需安裝套件或啟動模型服務。GitHub可能顯示原始碼，請先下載檔案再開啟。本資料夾不部署GitHub Pages，也沒有公開服務。

## 操作

- 四種情境：正常連線、HTTP洪流、SSH驗證嘗試及可疑Web流量。
- 預設2倍速，73秒示意時間約36.5秒播放完畢；也可選1倍或1.5倍。
- 播放／暫停、從頭開始、拖曳時間軸及章節跳轉都可直接操作。
- 點節點或輸入色格會暫停並展開資料；色格可用方向鍵移動、Enter／Space查看。
- Space播放／暫停，左右方向鍵前後5秒；控制項與對話框內保留各自鍵盤操作。
- 啟用減少動態效果時，選情境不自動播放，可依章節靜態閱讀。
- 可匯出JSON紀錄或再下載同一份HTML。匯出資料含示意來源及未執行模型／網路規則的標記。

## 展示範圍

本頁呈現方法關係與可操作流程，不是模型服務前端。封包、表徵、分類信心、案例及AI回覆為合成示意；向量正規化、cosine similarity、Top-5與簡化交易計數在頁面內計算。沒有呼叫CTBM、PBCNN、Llama、Mininet或外部API，也沒有執行畫面中的命令。

CTBM與PBCNN色格是簡化教學映射，不能取代正式訓練前處理；輸出已包含編碼與縮放說明。73秒時間軸不是推論耗時，30秒處置區段在2倍速下只播15秒，也不代表實際規則期限縮短。來源限速以其他來源背景流量維持通行作示意，同一受限來源的合法連線也可能受限，不能解讀為零副作用。原正式實測仍以主README及results為準。

## 字型與安全

使用共用白底、深藍、藍、青綠與少量暖金；中文及中文標點使用本機標楷體DFKai-SB，英文數字使用Times New Roman。不下載字型；若電腦缺少標楷體，瀏覽器會以系統字型替代，因此正式設備應先確認字型已安裝。封包RGB色格代表示意資料值，保留其資料色彩，不強制改成品牌色。

無外部腳本、字型、圖片或網路請求，匿名畫面不放GitHub帳號連結；HTML只在使用者按下載時建立本機檔案。實際模型展示仍使用[匿名控制台](../../scripts/showcase.py)。
