# 自動循環展示

[下載／開啟 HTML 單檔](AI資安框架_自動循環展示.html)。GitHub 可能顯示原始碼，請先下載再以瀏覽器開啟。無需連網、登入、套件或模型服務。本資料夾不部署公開網站。

## 操作

- 開啟即依序循環：正常流量 → DDoS → SSH → 人工複核 → 正常流量。
- 每個情境38秒，四個情境共152秒；可選1、1.5、2倍速。2倍速每個情境19秒，完整循環76秒。
- 目前處理中的節點會亮起並顯示提示；最後呈現處置指令送達。
- 可暫停、從頭開始、拖曳時間軸或點章節。點節點、色格、頁籤或案例會暫停，按播放才繼續，不會在閱讀時自行換情境。
- Space 切換播放，方向鍵前後5秒。輸入欄位、按鈕與對話框保留原有鍵盤行為。
- 系統啟用「減少動態效果」時不自動播放，仍可手動播放與跳轉；切換到其他分頁時不追趕背景經過時間。
- 可匯出目前情境 JSON，或另存完整 HTML。舊版 HTML 已由目前交付內容移除，歷史版本保留於 Git。

## 資料與方法範圍

本頁是合成資料教學示意，與正式實測分開。17類名稱及稽核提示對齊正式程式合約；頁面實際計算位元組轉色碼、529維向量正規化、相似度與Top-5排序。封包、分類、表徵、案例及稽核回覆為人工合成，未執行CTBM、PBCNN、Llama、Mininet或任何網路規則。

編碼色格為教學簡化，不能取代訓練前處理。時間軸是展示時間，不是推論耗時。情境在指令送達時結束，不呈現規則生效、攔阻率或TTL回復效果。人工複核情境不通過自動處置門檻。正式模型與實測證據請依主README及results查核。

## 驗證範圍

DOM回歸檢查四情境、多次完整循環、Top-5、策略門檻、暫停與調速、章節與鍵盤、減少動態、背景分頁、JSON與HTML匯出。SVG路徑幾何在DOM測試中使用替身；這不等於真實瀏覽器版面或原生投影片實播驗證。

## 視覺規格

延續PPT、A2海報與影片的共用色盤：白底、深藍標題、藍色流程線、青綠方法與完成狀態，暖金僅用於目前封包與少量提示。四階段導覽使用共用平面圖示並標示目前步驟。中文與中文標點使用標楷體DFKai-SB，其餘使用Times New Roman；未安裝對應字型的裝置會使用系統襯線字型。

UI固定色碼以design-system/palette.json為準，測試拒絕未列入色盤的固定顏色。輸入矩陣的RGB是資料編碼，保留計算結果；向量視覺以青綠透明度表示，不再使用彩虹色。自動循環與資料計算維持原設定。
