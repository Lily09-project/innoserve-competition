# A2海報製作與輸出規格

## 尺寸與視覺

- 單頁A2直式，420 × 594 mm，非16:9簡報縮放。
- 白色背景、淺灰#F4F7FA架構分塊，深藍#16324F標題、中藍#245EA8流程及青綠#087F8C成果長條、少量暖金提示，無裝飾陰影。
- 中文標楷體DFKai-SB，英文數字Times New Roman。
- 正式名稱44pt，區段25pt，方法標題23pt、流程節點20pt，輔助說明14至19pt，最末範圍說明16pt單行。
- 重要內容距裁切邊至少15mm。標準交付不加裁切線及出血，印刷廠另有要求時再輸出專用版本。
- 原創透明圖示沿用簡報；文字、箭頭、架構區塊及資料長條為原生可編輯物件。

## 閱讀順序

正式名稱與用途、四階段架構、三項創新、分階段實測成果、整合驗證範圍。架構改為由上至下1→2→3→4四條橫向方法流程；各條內部由左至右呈現輸入、處理與輸出。下方同事件識別碼帶表示產物銜接。

正式名稱三行置於淺灰標題區，以整張A2的210mm中線置中，下接金黃短線；四階段中的策略檢查明示允許動作，避免把動作白名單誤解為額外IP白名單功能。

海報不放學校、姓名、帳號、GitHub網址或二維碼。圖片為方法圖示，不宣稱是實機照片。

## 內容來源

數據從results四份JSON讀取並先經validate_results檢查。模型比較使用Macro-F1且長條以0至100%同尺度；本方法以青綠長條及深色粗體標示。Top-5、MRR@5及415／13／35均使用相同463筆查詢範圍。完整共用色板為design-system/palette.json，圖示使用共用平面向量，以中藍線條呈現。

## 重製

在已安裝python-pptx的製作環境執行：

```powershell
python scripts/presentation/build_a2_poster.py
powershell -ExecutionPolicy Bypass -File scripts/presentation/export_a2_poster.ps1
```

PDF與預覽由Microsoft PowerPoint實際輸出，PDF使用PDF/A選項以嵌入中英文字型。原生PPTX保留編輯能力，PDF供印刷，PNG供螢幕預覽。

## 驗收

檢查A2物理尺寸、單頁、字型、文字與圖示無裁切、數據一致、無匿名識別資訊及PDF字型嵌入。局部實際尺寸試印、紙材、印刷色彩及主辦單位另行指定的掛圖方式由操作者與印刷廠確認；本版沒有聲稱已完成實體打樣。

近期設計參考、查核範圍與原創轉譯方式見[海報與影片參考轉譯](../../docs/海報與影片參考轉譯.md)。

本輪以PowerPoint實際字形界線量測標題，相對整張海報中線偏差0.0257pt以內（約0.0091mm），小於0.1pt容差。主標題不再採靠左配置。


## 內容增補版

新增適用對象與使用流程、四個階段的具體產物、Top-5五張排序圖卡，以及FTP／SSH、HTTP型DDoS、Bot的策略例子。三項創新各以三行說明模型互補、529維證據與可追溯處置。底部六種隔離情境從results/framework_validation.json逐列讀取，分別標示正常、FTP、SSH、HTTP、XSS及Bot，以及實際規則／監測／蒐證路徑；背景保留與到期回復皆6/6。圖卡1至5表示檢索順位，不是捏造的案例分數。

主標題與四條方法區塊位置保持一致；新文字納入329個文字錨點及12項共同框格檢查，字形中線偏差仍在0.1pt內，重要文字位於15mm印刷安全區。


## 置中與優勢強化版（2026-10-30）

正式名稱44pt三行置中，主旨、章節、方法標籤、產物說明及三張優勢卡以各自區塊中心對齊；比較圖類別靠左、數值靠右，保留長條同尺度比較。優勢完整涵蓋內容／時間差／方向互補與17類融合、529維任務證據與正式分類保留，以及本機AI、同事件回條、策略檢查、讀回和到期回復。底部保留真實指標、誤判分流及隔離TCP驗證範圍。

比較長條新增0%、50%、100%共同刻度；整體準確率說明下移並保留在結果區，沒有新增數據或變更長條比例。
