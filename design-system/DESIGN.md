# 簡報、海報、影片與互動展示設計系統

## 證據鏈視覺系統（2026-10-30 重新設計）

四種成果的唯一樣式來源為[palette.json](palette.json)、[typography.json](typography.json)及[icons.json](icons.json)。這一輪依擁有者指示全面重做美感：保留頁序、內容、數據與時間軸，改寫字型、配色、版面與主視覺。

- **主視覺**：偵測 → 檢索 → 稽核 → 回復四個節點串在同一條線上，代表同一事件一路前進。封面、結尾、海報標題區與影片都使用這條鏈；簡報頁尾的九段進度條與架構圖底部的事件 ID 軸也延續同一概念。
- **畫布**：以淺色為主：簡報封面、結尾與方法影片以極淺灰#F3F6FA為底、白色卡片承載內容；內頁、海報內文與互動展示主畫面為白底。海報標題區同樣是極淺灰底。深夜藍#0B1B2E只用於標題文字、互動展示頁首與事件ID軸。深色面板#15293F、深色分隔線#2A4260只用在深色畫布。
- **顏色角色**：深夜藍做標題與深色面，訊號藍#1D4ED8表示流程與步驟，青綠#0F766E表示本方法、產出與成果數字，琥珀#F59E0B只標示「目前這一步」、封包與章節標記，不作白底文字。深色畫布上的重點文字使用青色#5EEAD4，輔助文字使用#A8B8CC。
- **字型**：中文及中文標點使用微軟正黑體Microsoft JhengHei，英文、數字與其他符號使用Segoe UI，混合文字依字元分段。兩者為Windows內建字型，比賽現場電腦開啟可編輯PPTX不會替換字型；海報PDF已嵌入字型。標題一律粗體、不加字距。
- **版面**：以留白與細線分區取代大量淺灰色塊；每頁一個視覺焦點，關鍵數字放大加粗（簡報62px、影片64px、海報Top-5 34pt）。卡片圓角10–18px，無陰影、漸層或立體材質。

白底文字對比：深夜藍17.6、訊號藍6.7、青綠5.5、正文#15233A 15.6、輔助#52637A 6.0；琥珀對白底不足4.5，因此只作色塊與標記。深色畫布上白字、青色與#A8B8CC皆高於7。

## 九頁順序與播放

封面→第2頁內嵌方法影片→四欄架構→雙模型判定→任務檢索與AI稽核→受控處置→偵測比較→稽核成果→結束頁。第2頁以全幅16:9內嵌H.264 MP4播放30秒；進入頁面播放一次，不循環、不自動跳頁，播放結束後由講者手動進入架構頁。另交付同一MP4作備援。PPT無換頁特效及裝飾動畫；第二頁的媒體播放時序保留。

封面與第9頁為極淺灰底（與第2頁影片同色，換頁不跳色），其餘內頁白底。頁首為琥珀小方塊＋英文章節標籤＋38px粗體標題；頁尾左側作品名、右側頁碼，中間九段進度條以琥珀標示目前頁。

第3頁架構改為由左到右的四條直欄：流量表徵、互補判定、證據稽核、受控回復，每欄內由上而下呈現輸入、處理與產出，底部以事件 ID 軸串起四欄。第4頁畫出CTBM／PBCNN同輸入分支與校準融合，第5頁由512＋17形成529維向量、Top-5訓練案例及三態稽核，第6頁以策略檢查、套用、讀回、到期回復及蒐證支線呈現。第7頁Macro-F1使用0–100%零基準長條；第8頁分流節點面積不編碼筆數。第9頁保留作品價值、同事件產物與答詢提示。

## 影片敘事

純程式SVG與確定性時間函式，以產品宣傳片節奏呈現；全片以淺色為主：極淺灰#F3F6FA底、深夜藍標題、白色卡片與設備台座、訊號藍重點。開場一顆發光封包劃過畫面、撞出光環後帶出作品名稱；每次換章以青色＋琥珀斜切光帶轉場，背景有放大描邊英文字（FEATURE、DETECT等）與漂浮粒子。網路拓樸與受控處置兩章採Packet Tracer式等角工作區：設備是浮在立方台座上的圖示，連線逐條畫出、連線燈由琥珀轉青，信封封包帶拖尾沿線流動；規則生效時策略閘道前升起琥珀護盾，異常封包撞上即碎裂打叉，到期後護盾消散。流量表徵把封包拆成三條資料流並遮罩識別欄位、框出流量切窗；判定章雙引擎合流到Gate，17格環狀表盤旋轉後鎖定；檢索章掃描案例庫、五張卡片飛出排成Top-5；稽核章以旋轉軌道環繞本機AI Judge並分出三種結果；成果數字由0跳到實測值。琥珀為異常流量、目前步驟與規則，訊號藍為正常流量、重點與模型，青綠為時間差線索、稽核與完成；色塊上的文字一律白字。無背景音樂，旁白見下方時間軸說明；畫面中的方塊、卡片與表盤只示意方法，不代表個別事件數值。

## 五分鐘正式報告

260秒口述＋30秒影片＋10秒正常操作＝300秒；另留60秒緩衝，不新增內容。詳細秒數見[決賽展示與答詢](../docs/決賽展示與答詢.md)。

## 答詢備用頁

正式報告第9頁結束，第10至12頁上下各放一題，共六題。每題左側以事件鏈、同事件產物、資料集合、誤判分流、驗證範圍或本機部署圖回答，右側青綠淡底突出實測證據；題號為深夜藍膠囊。頁尾標示答詢備用1/3至3/3。詳細完整答案保留於講者備忘稿；圖上僅留問題、關鍵節點、關係及數據。

## 插圖化說明

模型判定使用晶片與封包圖示，任務向量以括號與向量條示意，受控處置用盾牌、防火牆、讀回文件及到期時鐘呈現；支持、複核與不確定各有狀態圖示。深色畫布上的圖示以同一組向量重新上色（填色改深色、線條改青色），不另做點陣素材。所有圖像只表示物件或結構，不代表個別事件特徵值、機率或未測量效果。

## A2直式海報

尺寸420×594mm。淺灰標題區放正式名稱（46pt深夜藍粗體，靠左）、一句主旨與四節點證據鏈；下方白底依序為01四階段方法（四條橫向流程，每條由左至右呈現輸入、處理與產出）、事件識別碼軸、02三項優勢、03分階段實測。資料圖表使用0至100%同尺度，本方法青綠，其餘低彩度。交付原生PPTX、嵌入字型的PDF/A及螢幕預覽PNG，印刷以PDF為準。具體規格見[海報製作與輸出](../deliverables/source/poster-a2-spec.md)。

## 互動展示

HTML單檔沿用同一色票與字型：深夜藍頁首、白底流程面板、青綠目前節點、琥珀封包。中文字型以本機微軟正黑體為優先，未安裝時改用Noto Sans TC或PingFang TC；不載入外部字型檔。資料RGB矩陣是資料編碼，不受品牌配色限制。

## 對齊線驗收

所有原生文字依左、右或中心錨點量測實際字形邊界，目標保存在ALIGNMENT_TARGET_X標籤；校正後容差0.1pt。驗收圖以綠色表示靠左、藍色表示置中、紅色表示靠右，紫色表示主要框格與中心線。正式成果不含驗收線。第2頁換成影片後，原靜態頁文字的對齊標籤一併移除。

## 架構與檢查

架構維持四區、雙模型平行、529維任務向量與訓練庫讀取、正式分類不被AI改寫。文字及線條原生可編輯，圖示保持比例。細則見[架構圖設計與驗收](../docs/架構圖設計與驗收.md)。目前檢查涵蓋PowerPoint靜態匯出、逐頁PNG、最終MP4、資料一致性、內嵌影片雜湊及匿名；不執行原生播放。
