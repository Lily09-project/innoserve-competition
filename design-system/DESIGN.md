# 簡報與影片設計系統

依使用者提供的PlayStation風格design.md轉譯為原創資安作品，適用簡報、架構圖與獨立影片。

## 核心規則

- 黑#000000、白#FFFFFF章節交替，以背景切換分段；結語只使用一個全幅藍色#0070D1章節。
- 大標題輕字重；中文使用微軟正黑體Light/Regular，英文Arial。SST為專有字型，不冒用或附帶該字型。
- 正文24px、標題44px、說明18px、資料大字56px；16:9畫布1280×720。
- 平面面板8px圓角，提示按鈕全圓角；不使用舊版金屬斜角、霧藍底、橘金操作色與裝飾漸層。
- 方法圖與圖示承擔主要敘事，文字只留關鍵輸入、處理與輸出。所有數字取自results，AI僅生成無文字圖示。

## 架構圖

Python組合四個獨立分區：流量表徵、17類判定、證據檢索與稽核、受控處置與回復。實線表示處理順序，虛線表示同事件紀錄鏈結，並不宣稱線上持續學習。圖示600×600透明PNG，標籤另存SVG文字，可獨立編輯。Nature圖表指南參考：[分區與輸出](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/)、[可讀性規格](https://research-figure-guide.nature.com/figures/preparing-figures-our-specifications/)。投影字級依簡報需求放大，不照搬印刷稿字級。

## 影片製作基準

自主自由創作，保留Packet Tracer式網路拓樸、封包追蹤與事件鏈；以純時間函式SVG輸出，不仿製既有網站。使用者提供完整視覺規格，故略過額外styleframe確認。沒有選用Gallery特定鏡頭卡，不宣稱還原任何模板。原長60秒，40秒快版以1.5倍速輸出，無BGM與語音，供現場講解。

| 原速段落 | 鏡頭與動作 | 必須傳達內容 |
| --- | --- | --- |
| 0–5 | 黑底作品名稱，輕量進場 | 正式作品定位 |
| 5–13 | 白底拓樸，封包沿連線移動 | 正常與異常來源 |
| 13–22 | 表徵分支亮起 | 內容、時間差、方向 |
| 22–31 | 黑底偵測章節 | CTBM、PBCNN與OOF Gate |
| 31–40 | Top-5支線亮起 | 529維任務向量與訓練案例 |
| 40–48 | 黑底AI稽核章節 | 支持、複核、不確定 |
| 48–55 | 閘道規則提示與到期回復 | 策略檢查、讀回、回條 |
| 55–60 | 藍底實測結果 | 各評估範圍與正式數值 |

交付PPTX、MP4、PNG與SVG，README置頂簡報及影片。網站原始碼與Pages發布撤除，後端模型與API保留。
