# 產品動畫

預設為新封包任務動畫的45秒快版，由已交付90秒音效版等比例加速2倍、音訊保持音高，輸出720p H.264／AAC、faststart。播放器可切成約30秒或23秒，支援暫停、原生全螢幕、繁體字幕及方法段落跳轉；不自動播放。

- `media/product-45s.mp4`：獨立影片，可下載後放入PPT。
- `media/captions.vtt`：對齊快版時間的字幕。
- `fast-player.js`：速度、章節與播放狀態。
- `topology.html`：保留原150秒互動拓樸，供逐段解說使用；不是網站預設影片。
- `scene.mjs`、`player.mjs`：原互動拓樸原始碼。

影片為純程式動畫，非Packet Tracer軟體錄影。實際規則有效期仍為30秒；動畫呈現加速示意。實測數字與網站合成操作資料各自標示範圍。影片沒有語音，適合搭配口述。
